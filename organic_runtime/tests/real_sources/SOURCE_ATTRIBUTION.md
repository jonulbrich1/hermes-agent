# Source attribution

The experiment does not contain generated/synthetic knowledge passages. The searchable evidence corpus consists of real excerpts previously obtained from the following openly reusable works.

## Project Gutenberg - public domain in the USA

- George Francis Atkinson, *Elementary Botany* - https://www.gutenberg.org/ebooks/64601
- Eliza Frances Andrews, *A practical course in botany* - https://www.gutenberg.org/ebooks/78430
- L. H. Bailey, *Beginners' Botany* - https://www.gutenberg.org/ebooks/73531
- George William Hunter, *A Civic Biology* - https://www.gutenberg.org/ebooks/39969
- Norman Taylor, *Botany: The Science of Plant Life* - https://www.gutenberg.org/ebooks/49211
- Ernest Stenhouse, *An Introduction to Nature Study* - https://www.gutenberg.org/ebooks/61273
- Roscoe W. Thatcher, *Plant Life* - https://www.gutenberg.org/ebooks/33394
- William Mansfield, *Histology of Medicinal Plants* - https://www.gutenberg.org/ebooks/65569

## BCcampus Open Education - CC BY 4.0

- Charles Molnar and Jane Gair, *Concepts of Biology - 1st Canadian Edition* - https://opentextbc.ca/biology/

Each source file contains its own title, author, URL, and license-status header. Runtime SHA-256 hashes are written to `output/source_manifest_runtime.json`.
